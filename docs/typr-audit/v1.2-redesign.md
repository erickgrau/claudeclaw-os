# Mabel v1.2: Full UI redesign + local stats

Builds on v1 + v1.1. Lifts the structural ideas from a competitor product
($144/yr cloud subscription) and applies them in Mabel's voice with the
forever-local privacy stance.

## What's in this patch

### Sidebar restructure

Old: 3 nav items (General, Engine, Recording) corresponding to settings.

New:
- **Home** (the new dashboard, default landing)
- **Dictionary** [PRO, greyed]
- **Snippets** [PRO, greyed]
- **Style** [PRO, greyed]
- **Transforms** [PRO, greyed]
- **Scratchpad** [PRO, greyed]

Footer: Activate Pro · Settings · Help.

Settings is no longer a sidebar item. It opens as a modal overlay with its
own internal nav (General / Engine / Privacy / Account / About). Cleaner
information architecture and frees up the sidebar to advertise Pro features.

### Home dashboard

Replaces the old "General" page as the default view. Cards:

- **Status row** — Ready / Recording / Transcribing pill, current hotkey
  next to it (clickable to rebind in place).
- **Today** — words and dictations since midnight.
- **All-time** — running counters since first use.
- **Streak** — consecutive days with at least one dictation. Includes a
  "Last dictation: N min ago" relative time.
- **Pro upsell card** — describes what Pro unlocks, with a Mabel-cat
  illustration in the corner.
- **Privacy footer line** — "0 audio files saved · 0 transcripts uploaded ·
  100% on your Mac".

### Pro upsell pages

Each Pro nav item routes to its own placeholder page in the content area:

- Dictionary
- Snippets
- Style
- Transforms
- Scratchpad

All five share the same layout: PRO eyebrow, headline, one-paragraph
description, "Activate Pro" CTA, "Coming in v2" footnote. v2 will replace
these placeholders with the real implementations.

### Activate Pro modal

Opens from any "Activate Pro" CTA. Shows the v2 feature list:

- AI cleanup (on-device LLM)
- Custom vocabulary
- Voice snippets
- App-aware formatting
- iCloud settings sync

Plus pricing ($10/mo · $99/yr · $129 lifetime) and a footnote that free is
forever, no caps.

### Help modal

Quick start, permissions explanation, "where logs live" pointer.

### Local stats (Rust)

New `src-tauri/src/stats.rs` module:

- `Stats` struct with `total_dictations`, `total_words`, `total_chars`,
  `first_used`, `last_used`, and a `BTreeMap<date, DayStats>` for per-day
  rollups.
- `StatsView` is the projection sent to the frontend with derived metrics
  (today's totals, day streak).
- Persists to `~/Library/Application Support/com.mabel.app/stats.json`.
- **Counts and dates only. Never any transcript content.**
- Day-streak computation walks back from today through consecutive days
  with at least one dictation.
- Bundled with self-contained date math (Howard Hinnant's algorithm) so we
  don't need a chrono dep.

Wired into `recorder::stop_and_transcribe` in both the Tauri-command and
push-to-talk-release paths. After every successful transcription, character
and word counts are tallied. The frontend gets a `stats-updated` event
emitted via Tauri so the dashboard updates live.

New Tauri commands:
- `get_stats() -> StatsView`
- `reset_stats()` — zeroes the file and emits an update event.
- `open_app_data_dir()` — `open` the app data directory in Finder for the
  Privacy tab.

### Persian cat icon (placeholder)

`src-tauri/icons/mabel-source.svg` is a stylized cat face based on Mabel's
actual coloring (silver-grey, white chest fluff, pink nose, green eyes).
Squircle background in the warm peach pulled from Chie's painting palette.

This is a placeholder. Real icon path: take a flattering photo from her
Instagram, run through Recraft / ChatGPT image gen with a "stylize as
macOS app icon" prompt, then `npm run tauri icon path/to/mabel.png`.

### README replaced

Old: the unmodified Tauri + Vanilla TS template README.

New: Mabel-specific README covering what it does, build steps (whisper.cpp
sidecar setup, dev mode, release build), permissions it asks for, privacy
posture, roadmap, and license.

No mentions of the old project name, the upstream fork, or template
boilerplate.

### Visual identity shift

Color palette moved from a generic indigo accent (`#5e6ad2`) to a warm
salmon-pink (`#E89898`) pulled from Mabel's nose color and the painting's
palette. Plus a "Pro" gold accent (`#C8A86B`) for tier indicators. Headers
and stat values use IBM Plex Serif for a less-techy feel; everything else
stays in IBM Plex Sans.

Backgrounds lean slightly warmer (#0E0D0B vs the old #09090b cool black) to
match the cat-and-painting palette without going precious.

## What's NOT in this patch

- Real implementations of any Pro feature. They're placeholders.
- License validation against a server. That's v2 with mabel-cloud.
- Notarization or code signing. Still unsigned.
- Multi-language support. English only.
- Settings sync. Local only.
- Apple Developer ID setup. v2 prerequisite.
